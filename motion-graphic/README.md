# گهرترابر — موشن‌گرافی پیام مدیریت حمل‌ونقل داخلی

یک موشن‌گرافی عمودی (۹:۱۶) با روایت فارسی، طراحی‌شده برای صفحهٔ موبایل.

**پخش:** فایل `index.html` را از طریق یک وب‌سرور محلی باز کنید (به‌دلیل بارگذاری فایل داده‌ها، بازکردن مستقیم با `file://` کار نمی‌کند):

```bash
cd motion-graphic
python3 -m http.server 8080
# سپس در مرورگر:  http://localhost:8080
```

---

## نسخه ویدیویی

خروجی MP4 آماده در `video/gahar-motion-1080x1920.mp4` است (۱۰۸۰×۱۹۲۰، ۳۰ فریم‌برثانیه، H.264/AAC،
مناسب واتساپ، تلگرام و اینستاگرام). از دکمهٔ «دانلود نسخه ویدیویی» در صفحهٔ شروع هم قابل دریافت است.

## ساختار

```
motion-graphic/
├─ index.html                 ← صفحهٔ اصلی (صحنه، کنترل‌ها، پردهٔ شروع)
├─ assets/
│  ├─ css/style.css           ← طراحی و انیمیشن‌ها (بوم ۱۰۸۰×۱۹۲۰)
│  ├─ js/app.js               ← موتور پخش: هم‌زمان‌سازی صدا، فصل‌ها، زیرنویس
│  ├─ data/scenes.json        ← متن روایت، زیرنویس و بلوک‌های تصویری هر فصل
│  ├─ audio/                  ← روایت هر فصل (s01…s10) + موسیقی پس‌زمینه
│  └─ fonts/                  ← وزیرمتن (SIL OFL)
└─ README.md
```

## ویژگی‌ها

- **۱۰ فصل** منطبق بر ۱۵ بند پیام؛ روایت نرم فارسی، هم‌زمان با ظاهرشدن عناصر تصویری.
- **موبایل‌محور:** بوم طراحی ۱۰۸۰×۱۹۲۰ که روی گوشی تمام‌صفحه و روی دسکتاپ به‌شکل کارت سینمایی نمایش داده می‌شود.
- **زیرنویس هم‌زمان** (برای تماشای بی‌صدا) + موسیقی ملایم پس‌زمینه با قابلیت قطع صدا.
- **کنترل‌ها:** پخش/توقف، نوار زمان (جابه‌جایی بین فصل‌ها)، صدا، تمام‌صفحه؛ کلیدهای `Space`، `←`، `→`، `M`، `F`.
- **دسترس‌پذیری:** راست‌به‌چپ، اعداد فارسی، احترام به `prefers-reduced-motion`، برچسب‌های ARIA.
- بدون وابستگی خارجی؛ فونت و صداها همه محلی هستند.

## ویرایش متن یا زمان‌بندی

همه‌چیز در `assets/data/scenes.json` است:

- `title` / `accent`: تیتر هر فصل و واژه‌هایی که طلایی نمایش داده می‌شوند.
- `beats[]`: هر «جملهٔ روایت» با `narration` (برای زمان‌بندی) و `caption` (زیرنویس).
  زمان ظاهرشدن هر بلوک تصویری از روی طول متن و مدت همان فایل صوتی محاسبه می‌شود.
- `blocks[]`: عناصر تصویری هر فصل (`card`، `checklist`، `ladder`، `chips`، `badge`، `note`، `people`، `quote`، `lead`) و شمارهٔ `beat` مربوط به آن.

اگر متن یک فصل را عوض کردید، فایل صوتی همان فصل (`assets/audio/sXX.mp3`) را هم جایگزین کنید؛
زمان‌بندی به‌طور خودکار با مدت صدای جدید هماهنگ می‌شود.

## پیوند مستقیم به یک فصل

```
index.html?scene=5          # پخش از فصل ۵
index.html?scene=5&hold=1   # نمایش ثابت فصل ۵ (برای بازبینی طراحی)
```
